# Java Login System (Swing + MySQL)

A simple Java Swing-based Login System integrated with a MySQL database using JDBC.

This project demonstrates how to build a basic authentication system using:
- Java Swing (GUI)
- JDBC (Database Connectivity)
- MySQL
- PreparedStatement (Secure Queries)

---

## Features

- ✅ User Login Authentication
- ✅ MySQL Database Integration
- ✅ Simple and Clean GUI
- ✅ Secure Query using PreparedStatement
- ✅ Database Creation via Java

---

## Tech Stack

- Java (JDK 8+)
- Java Swing
- MySQL Server
- JDBC (MySQL Connector)
